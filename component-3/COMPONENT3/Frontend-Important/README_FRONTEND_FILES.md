# Component 3 Important Frontend Files

| File | Main purpose |
|---|---|
| `main.jsx` | Starts the React dashboard. |
| `App.jsx` | Controls pages, routes and workflow steps. |
| `Inputs.jsx` | Accepts and validates C1/C2 inputs. |
| `DesignStack.jsx` | Shows design, coverage and stack selection. |
| `Generation.jsx` | Starts generated-project creation. |
| `BrowserPreview.jsx` | Runs and displays the local Docker preview. |
| `Traceability.jsx` | Shows requirement-to-test traceability. |
| `Readiness.jsx` | Shows final evidence and readiness gates. |
| `HybridViews.jsx` | Displays hybrid preview, trace and readiness results. |
| `endpoints.js` | Connects frontend actions to backend routes. |
| `traceGraph.js` | Builds traceability chains for display. |
| `useHybridRun.js` | Manages hybrid generation, preview and trace state. |

These are study copies. The running application continues to use the original files under `component-3/dashboard/src`.
