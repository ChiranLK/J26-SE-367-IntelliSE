# Intelligent-End-to-End-Agile-Software-Engineering-Platform

## Start Component 01 locally

From this repository directory:

```sh
./start-component-1
```

This starts/checks local MongoDB, the configured extraction provider, the full
audio-enabled backend and the frontend, using existing prepared environments and
models. No Azure/Whisper API key is needed for local audio transcription.
Read [startup instructions](component-1/frontend/docs/local-startup.md) for the
one-time prerequisites, settings, occupied ports and shutdown behavior.
